Chairlift Chat は、スキー用カメラのための公開プロダクト相談所です。実際に雪山で困ったことを持ち寄り、ほかの人が補足したり反対したり、投票したりします。決まったことと、その理由は公開で残します。企画書も肩書きも必要ありません。

## 🎯 どこに書けばいい？

| 手元にあるもの | 行き先 | 書くこと |
| --- | --- | --- |
| 😅 具体的な困った体験 | [体験を書く](https://github.com/Zionlzx/chairlift-chat/issues/new?template=story.yml) | どこで何が起き、どう対処したか |
| 💡 具体的な改善案 | [改善案を出す](https://github.com/Zionlzx/chairlift-chat/issues/new?template=feature-request.yml) | 何を変えたいか、いつ使うか、代償は何か |
| 💭 まだ形になっていない考え | [Discussions](https://github.com/Zionlzx/chairlift-chat/discussions) | 質問、反例、別の使い方 |

一文だけでも大丈夫です。

> 氷点下で厚いグローブをしていると録画ボタンが押せない。気づいた時には、一番いい数秒が消えていた。

## 🛠️ 体験から改善まで

<p align="center">
  <img src="assets/slope-notes.svg" alt="実際の体験から議論、検証へ" width="100%" />
</p>

流れはシンプルです。**実際の体験 → 補足と反論 → 判断 → 進捗を公開**。

リアクションは目安で、約束ではありません。ひとつの具体例や反例が、たくさんの投票より判断を変えることもあります。判断の理由は必ず元の投稿に残します。

## 🏷️ ステータスラベル

| ラベル | 意味 |
| --- | --- |
| `idea` | 出たばかり。体験を集めている段階 |
| `discussing` | 方法とトレードオフを話し合っている |
| `planned` | 近い時期の計画に入った |
| `shipped` | 試せる、または検証できる |
| `declined` | 今はやらない。理由は投稿に残す |

[Issues](https://github.com/Zionlzx/chairlift-chat/issues) はラベルで絞り込めます。全体の進み方は [公開ロードマップ](ROADMAP.md) を見てください。

## 🧭 この場所の雰囲気

- できるだけ普通の言葉で書く。空っぽのプロダクト用語は使わない。
- 人ではなく、案や前提に反対する。場面、リスク、代案を添える。
- 肩書きは背景情報であって、発言の重みを自動で増やさない。
- まだ決まっていない特典や優先権を約束しない。

[参加ガイド](CONTRIBUTING.md)、[運営方針](GOVERNANCE.md)、[行動規範](CODE_OF_CONDUCT.md) も読んでください。
