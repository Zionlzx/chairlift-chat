# chairlift-chat · 野生产品经理

我们在做一副**滑雪运动眼镜**。这个仓库，就是大家一起把「它该长成什么样」定下来的地方。

## 这是什么

一副滑雪眼镜能塞的功能挺多：拍视频、防起雾、报速度、摔了自动呼救……先做哪个、怎么做，光靠我们几个拍脑袋没用，得靠真滑过雪的人来定。

所以这里就干一件事：你提想法，别人投票，我们做，然后把结果摊开给你看。一个产品是怎么被一点点吵出来的，全程你都能看见。

不会编程没关系，一句话的想法也算数。你只需要真的滑过雪，或者真的被一副眼镜坑过。

## 为什么叫 chairlift-chat

滑雪的人最闲、话最多的那几分钟，就是坐缆车的时候，好点子基本都在这会儿冒出来。这里就当一条永远到不了顶的缆车，你随时上来聊两句。

## 为什么是「野生」的

大厂产品经理在会议室对着 PPT 猜用户要什么。你是真的在雪道上摔过的那个，感受比报表准。

- 零下十几度手机冻关机、戴着手套按不到键盘、镜头起雾录了半小时废片。这些不是需求文档，是你碰上过的破事。
- 一个人容易漏，一百个滑雪的人一起就漏不掉。想法摆出来、投票、吵一架，答案自己会出来。
- 顺便你能从头看到尾：一个想法怎么被提、怎么被投、怎么被砍、怎么被做出来。比闷头看十本书都值。

## 怎么参与

1. **提想法**：去 [Issues](https://github.com/Zionlzx/chairlift-chat/issues) 发一个「功能建议」，一句话也行。
2. **投票**：认同哪个就点个赞。你不是来当用户的，是来当没配工牌的产品经理的。
3. **闲聊**：去 [Discussions](https://github.com/Zionlzx/chairlift-chat/discussions)，聊那些还不成形、但很带感的念头。

## 一个想法会经历什么

```text
提出想法 → 归类去重 → 投票 → 官方裁决 → 结果公示
```

- 相似的想法会并到一起，打个标签（拍摄 / 剪辑 / 连接 / 续航……）。
- 没被采纳的，我们会写清楚为什么：成本、定位冲突，还是技术上暂时做不到。
- 投票是参考，不是承诺。最后拍板的还是我们，但保证每条想法都有个交代。

## 产品进度

产品还在做。哪些被采纳、哪些卡住了，都会实时写在 [ROADMAP.md](ROADMAP.md) 里，跟着看一个产品怎么长出来。

## 共创的乐趣

在这里你不是路人，是**云股东**。

- **云股东**：想法被采纳，自动进 [云股东名册](SHAREHOLDERS.md)。这是荣誉，不是股权，图的是「这产品有我一票」。
- **开拓者徽章**：最早的一批云股东，会拿到「开拓者」徽章。
- **设备优先体验**：进测试阶段后，云股东优先拿到设备体验。
- **彩蛋福利**：还有些福利细则在敲，先不多说，保底不亏。

## 实时围观与在线掰头

- 谁点赞、谁留言，头像都留在上面。点 Watch，有人说话、有新想法，第一时间提醒你。
- 掰头区里，支持派和反对派可以正面吵。就一条规矩：对事不对人。

## 响应节奏

- 我们每周至少集中回一次新想法，采纳、排期还是暂缓，都会给理由。
- 被采纳的想法，会在更新里写上提出人。
